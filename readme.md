# PHP Roadmap Learning

Learning PHP through hands-on projects based on the [roadmap.sh PHP Roadmap](https://roadmap.sh/php).

This repository contains my practical PHP learning journey from fundamentals to advanced PHP concepts, database programming, OOP, Composer, testing, API integration, and server-side topics.

## 🎯 Goals

* Follow the PHP Roadmap step by step.
* Practice every topic through coding.
* Build practical projects instead of only reading theory.
* Use Git and GitHub throughout the learning process.
* Use Conventional Commits for every meaningful change.
* Complete 120 practical learning steps.
* Build a strong PHP foundation before moving deeper into Laravel.

# 🔀 Git Workflow

Every completed lesson should follow this workflow:

```text
Learn roadmap topic
       ↓
Write PHP code
       ↓
Test the code
       ↓
Review the result
       ↓
Commit
       ↓
Push to GitHub
       ↓
Check the corresponding roadmap.sh topic
       ↓
Move to the next lesson
```

## Basic Commands

```bash
git status

git add .

git commit -m "feat(scope): add lesson implementation"

git push
```

---

# 📝 Conventional Commits

This repository uses Conventional Commits.

### Feature

```bash
git commit -m "feat(basics): add PHP syntax examples"
```

### Fix

```bash
git commit -m "fix(form): validate empty input"
```

### Refactor

```bash
git commit -m "refactor(user): simplify user class"
```

### Tests

```bash
git commit -m "test(auth): add login tests"
```

### Documentation

```bash
git commit -m "docs(readme): update learning progress"
```

### Chore

```bash
git commit -m "chore(project): update project configuration"
```

# ✅ Completion Rules

A lesson is considered complete when:

* [ ] The roadmap topic has been studied.
* [ ] PHP code has been written.
* [ ] The code has been executed/tested.
* [ ] The implementation is stored in the correct project directory.
* [ ] A meaningful Conventional Commit has been created.
* [ ] The changes have been pushed to GitHub.
* [ ] The corresponding roadmap.sh topic has been checked.
